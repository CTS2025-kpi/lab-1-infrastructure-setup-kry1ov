#### Створення IaM Identity Center та користувача-адміністратора
В пошуку знаходимо IaM Identity Center, натискаємо "Enable" для активації сервісу і залишаємо Identity Source за замовченням.
![[2.png]]
В лівій панелі переходимо до вкладки Users та створюємо нового користувача через кнопку "Add user". Заповнюємо форму такими даними:
- Ім'я користувача
- Електронна адреса
- Повне ім'я
Після цього на вказану електронну скриньку приходить лист з посиланням для активації користувача. Після виконання цієї процедури користувач має порожнє вікно в AWS access portal.
![[3.png]]
Зі сторінки dashboard в IaM Identity Center переходимо до вікна Permission sets в панелі ліворуч та створюємо "Create permission set" з налаштуваннями "Predefined permission set" та опцією "AdministratorAccess".
В меню "Aws accounts" з панелі ліворуч обираємо користувача та натискаємо "Assign users or groups", проходимо прості кроки та надаємо новоствореному користувачеві права адміністратора.
![[4.png]]
Після цих кроків у користувача з'являться нові "Permission sets".
![[5.png]]
Тоді AWS access portal матиме такий вигляд.

#### Створення View only користувача
Повторюємо кроки зі створення Permission Sets для адміністратора та створюємо по готовим шаблонам дозволів користувача, якому присвоюємо дозволи ViewOnlyAccess.
![[8.png]]
З AWS access portal новоствореного користувача Viewer перейдемо до консолі і спробуємо запустити ЕС2. Оскільки він має право тільки переглядати ресурси, запуск завершується помилкою.
![[9.png]]
#### Створимо роль з такими ж правами доступа
На першому кроці створення ролі введемо trusted entity - користувача, якому слід надати можливість приймати цю роль. 
ID головного користувача (admin) - 694226983293
![[10.png]]
Оскільки роль належить до сервісу IaM, користувач має бути також створений в ній.
Щоб користувач міг приймати роль, йому слід додати політику.
